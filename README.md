# Laras

**Selaraskan hari, tentukan langkah.**

Laras adalah personal life management web app untuk membantu pengelolaan kegiatan, prioritas, rekening, pemasukan, pengeluaran, dan rekomendasi personal berdasarkan pola penggunaan.

## Status

Project foundation and documentation.

## Technology

- Laravel 13
- PHP 8.3
- MySQL
- Blade
- Tailwind CSS
- JavaScript
- Vite

## Local Development

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm run dev
php artisan serve
